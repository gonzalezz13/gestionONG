English Version 
This project involves the development of a web application designed to improve volunteer management within NGOs. The idea arose after identifying a fairly common problem: many organizations still rely on inefficient tools such as spreadsheets and messaging apps, which complicates shift organization, activity tracking, and the monitoring of volunteer hours.

Capítulo 2. Idea del proyecto y análisis inicial 
En este capítulo explicamos cómo surge la idea del proyecto, el proceso seguido para definirla y el análisis del entorno en el que se desarrolla. Todo esto ha servido como base para construir una solución realista y útil dentro del sector del voluntariado. 
2.1 Origen de la idea y problema detectado 
El proyecto nace a partir de un problema bastante común en muchas ONG: la gestión del voluntariado se realiza mediante herramientas poco organizadas como hojas de cálculo, listas en papel o mensajes sueltos en aplicaciones como WhatsApp. Esto provoca confusión en los turnos, errores en la asistencia y dificultades para llevar un control de las horas realizadas. 
Además, esta forma de trabajar hace que la información esté dispersa, lo que complica la organización y reduce la eficiencia. Por eso se detectó la necesidad de crear una herramienta que centralice toda esta gestión en un único sistema.
2.2 Solución propuesta 
Como solución, nos planteamos el desarrollo de una aplicación web accesible desde distintos dispositivos (móvil, ordenador o tablet). Esta aplicación permitirá a la ONG gestionar voluntarios, actividades y turnos, así como registrar la asistencia y las horas realizadas. 
Por otro lado, los voluntarios podrán registrarse, indicar su disponibilidad, consultar sus turnos y conocer la información de las actividades en las que participan. 
La idea principal es simplificar todo el proceso y hacerlo más claro, evitando depender de múltiples herramientas y reduciendo errores. 
2.3 Proceso de creatividad e innovación 
Para llegar a esta idea final, hemos seguido un proceso de creatividad estructurado. En primer lugar, realizamos una lluvia de ideas (brainstorming), donde se propusieron diferentes tipos de aplicaciones, como una web para buscar piso, reportar incidencias o gestionar reservas. 
Después de analizar las opciones, elegimos la gestión de voluntariado porque respondía a una necesidad real y era viable como proyecto. 
También aplicamos la técnica SCAMPER, que permitió mejorar la idea inicial. Por ejemplo, se sustituyeron las listas en papel por una web, se combinaron varias funcionalidades en un solo sistema y se reorganizó toda la información para hacerla más clara. 
Además, utilizamos el enfoque Design Thinking, que ayudó a entender mejor las necesidades de las ONG. Se analizó cómo trabajan actualmente, se definió el problema principal y se planteó una solución adaptada a esa realidad. 
Gracias a todo este proceso, la idea final no surgió al azar, sino como resultado de un análisis previo y una planificación. 
2.4 Análisis del entorno (DAFO y PESTEL) 
Para comprobar la viabilidad del proyecto, se realizó un análisis del entorno utilizando herramientas como el DAFO y el PESTEL. 
En el análisis DAFO, se identificaron como principales fortalezas la centralización de la información, el ahorro de tiempo y el control de asistencia y horas. Como debilidades, se detectó que puede costar adaptarse al sistema y que es importante gestionar bien los datos. En cuanto a oportunidades, destaca el crecimiento de la digitalización en las ONG, mientras que como amenazas existen otras plataformas similares y posibles riesgos legales.
Por otro lado, el análisis PESTEL permitió ver el contexto general. A nivel social, se valora mucho mejorar la organización del voluntariado. A nivel tecnológico, el uso del móvil facilita la adopción de este tipo de herramientas. También se identifican aspectos legales importantes, como la protección de datos personales, que deben cumplirse correctamente.
2.5 Benchmarking 
Además, se analizaron plataformas existentes como VolunteerHub o Better Impact, que ya ofrecen soluciones similares para la gestión de voluntarios. 
De estas herramientas se tomaron ideas importantes, como: 
● La organización clara de turnos 
● El uso de recordatorios para evitar fallos 
● El control de horas y generación de informes 
Esto ha servido como referencia para diseñar una aplicación que cumpla con las necesidades detectadas. 
2.6 Objetivos del proyecto 
El objetivo principal es desarrollar una aplicación web que permita gestionar voluntarios, actividades y horas de forma organizada y accesible. 
Para conseguirlo, se definieron varios objetivos concretos: 
● Crear un sistema de registro y login
● Permitir la gestión de actividades y turnos
● Mostrar la disponibilidad de los voluntarios
● Registrar la asistencia y las horas realizadas
Estos objetivos ayudan a estructurar el desarrollo del proyecto y a medir si se cumplen los resultados esperados.
